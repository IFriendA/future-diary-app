# 未来日记 MVP 产品说明

## 产品定位

让用户写下“明天已经发生的事情”，再由明天的自己以第一人称，把经历、感受和鼓励送回今天。

未来人格不是教练、宠物或旁观者，而是用户本人处在明天的时间坐标上。它可以替今天暂时不敢做、做不到的自己先勇敢一次，但不能高高在上地评价用户。

## 核心闭环

1. 用户自由书写明天的一天，不填写复杂表单。
2. AI 在后台解析事件、时间窗口、期待、情绪与完成信号，原文始终是唯一可信正文。
3. “明天的我”以第一人称生成一组未来记忆片段。
4. 系统按照具体时间或合理的随机时间窗口发送片段，而不是固定每天只发一次。
5. 用户可以标记完成、部分完成或暂未完成；完成时获得轻量正反馈，未完成时得到具体安慰并可顺延。
6. AI 根据真实结果逐渐学习用户的表达方式、行为规律和需要的鼓励方式。

## 未来人格硬规则

- 永远以“我”表达自己的经历、想法和感受。
- 不得以“他/她/用户”等第三人称观察或评价用户。
- 与用户保持同一身份、价值观和脆弱面，只多出一天的经历与行动感。
- 不做心理医生，不制造羞耻感，不用连续打卡威胁用户。

## 第一阶段范围

- Expo + React Native + Expo Router 通用工程。
- 网页版部署到 Vercel，适配手机浏览器。
- 后续可使用同一代码库构建 iOS 与 Android。
- 本次先建立可运行、可部署的工程基础；不实现社交、AI 间聊天、装饰商店和复杂成就。

## 技术边界

- 前端使用 Expo 通用应用。
- Vercel 当前只承载静态 Web 版本；后续 API 独立放在 Vercel Functions 或单独服务中。
- 原生推送与原生安装包后续通过 Expo EAS 接入。
- AI 服务密钥不得放进客户端代码。

## 本次验收

- 本地 Web 构建成功并生成 `dist/`。
- 项目提交到 GitHub `main`。
- Vercel 能从仓库自动完成构建与发布。
